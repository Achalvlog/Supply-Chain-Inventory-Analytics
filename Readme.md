# 📦 Supply Chain & Inventory Analytics

## 📌 Project Overview

This project analyzes sales, inventory, product, depot, and customer data to identify business trends and inventory-related issues.

The project follows an end-to-end Data Analytics workflow using **Excel, MySQL, and Power BI**.

The main objective is to help identify:

- High and low-performing products
- Slow-moving products
- Depot-wise sales performance
- Inventory levels
- Days of Inventory
- Regional performance
- Sales trends over time

---

## 🛠️ Tools & Technologies

- **Excel** – Data cleaning, preparation and initial analysis
- **MySQL** – Data querying and business analysis
- **Power BI** – Interactive dashboard and visualization
- **DAX** – Measures and calculated business metrics
